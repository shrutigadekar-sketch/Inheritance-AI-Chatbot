# Inheritance Buddy — C++ Unit 2 Chatbot

A beginner-friendly, responsive website chatbot based on the uploaded **Object-Oriented Programming with C++ — Unit 2: Inheritance** notes for SY B.Tech AI & DS.

## Run it
1. Extract `Inheritance_AI_Chatbot.zip`.
2. Open the folder.
3. Double-click `index.html` to open it in Chrome, Edge, or another browser.
4. Type a question or use the topic buttons.

No installation, server, API key, or internet connection is required.

## Topics covered
- Inheritance, base class, derived class
- Access specifiers and inheritance modes
- Single, multilevel, multiple, hierarchical, and hybrid inheritance
- Constructors and destructors
- Function overriding
- Class hierarchies and is-a / has-a relationships
- Multiple inheritance ambiguity
- Virtual base class and diamond problem
- Abstract classes, friend classes, nested classes
- Basic single-inheritance code and MCQ practice

## Important note
This starter version uses keyword-based answers in JavaScript. It is not connected to a live generative AI model. To make it a true AI chatbot that can answer arbitrary questions from the full PDF, connect a backend to an AI API and add PDF retrieval (RAG). Never put a private API key directly in browser JavaScript.
